# ACP agents

Create agents that run any harness speaking the Agent Client Protocol (ACP) and answer you in Buzz. Each conversation continues its own agent session.

## Getting started

1. Turn on **ACP agents** in **Settings → Plugins → Manage plugins**. It is off by default.
2. Install and sign in to your harness yourself; Buzz doesn't include it.
3. Go to **Agents** and create an agent with **ACP agent** as its **Harness**.
4. Open the agent's **Settings**, pick a preset or enter the command that starts your harness, and choose **Save**.
5. Review the exact command and choose **Confirm command**. Any later change to the command needs confirming again.
6. Mention your agent in a conversation to give it work.
