# ACP agents

Create agents that run any harness speaking the Agent Client Protocol (ACP) and answer you in Buzz. Each conversation continues its own agent session.

## Getting started

1. Turn on **ACP agents** in **Settings → Plugins**. It is off by default.
2. Go to **Agents**, create an agent with **ACP agents** as its **Harness**, and pick a preset or enter the command that starts your harness.
3. Install and sign in to that harness yourself; Buzz doesn't include it.
4. Review the exact command in the agent's settings and choose **Confirm command**. Any later change to the command needs confirming again.
5. Mention your agent in a conversation to give it work.
