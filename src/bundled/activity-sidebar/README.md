# Activity sidebar

A prototype sidebar for Messages that lists your conversations newest first,
each with its latest message.

## Getting started

1. Turn the plugin on. The Messages sidebar changes at once.
2. Choose **Solo** for your chats with agents, or **Team** for channels and DMs.
3. Under Solo, **Working** shows chats where an agent is busy, and **Waiting**
   shows chats where an agent replied last. Under Team, **Direct** shows your
   DMs and messages that mention you.
4. Turn on **Unread** to see only conversations with something new.

---

## Details

- Turn the plugin off to get the original Messages sidebar back.
- It covers what the Activity page shows, so you can turn Activity off too.
