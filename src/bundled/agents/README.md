# Agents

Your home for creating and managing agents. Set them up, group them into teams, and find agents others in your community have shared.

## Getting started

1. Open **Agents** and choose **New agent**.
2. Pick **Create a new agent**, **Import an agent**, or **Browse the marketplace**.
3. Use **More agent actions** → **Provider settings** to install or sign in to an agent type such as Claude or Codex.
