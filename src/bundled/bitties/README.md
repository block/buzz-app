# Bitties

Give an agent a pixel avatar drawn from its name.

## Getting started

1. Create an agent, or open an agent's **Change avatar**, and choose the **Bitties** tab in the avatar picker.
2. The Bitty follows the name as you type. **Shuffle** picks a random one, the lock keeps the current one through renames, and the strip offers twelve more for the same name.
3. Save. The Bitty is uploaded as an ordinary image, so later renames don't change it and it stays if you turn this plugin off.

Turn Bitties off in **Settings** → **Plugins** to remove the tab.

---

Bitties are an original grammar of front-facing, mirror-symmetric pixel busts on a 12 × 12 grid; no catalog art. This plugin is the first consumer of `ctx.agents.registerAvatarSource`. See [the plugin architecture](../../../docs/plugin-architecture.md).
