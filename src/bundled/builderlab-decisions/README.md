# Builderlab decisions

Answers the app's decisions with your Builderlab account, instead of a
TypeSafe key. Attention uses decisions to check which events should wake an
agent.

## Getting started

1. Turn on this plugin. It also needs the **Builderlab** plugin, which is on
   by default.
2. Buzz selects **Builderlab** in **Settings > Decisions API**. If you are not
   signed in, Buzz opens Builderlab sign-in in your browser.
3. Finish sign-in in your browser.

Builderlab answers only for accounts it has turned decisions on for. Decision
text can include private messages, so Buzz moves it to Builderlab only when you
turn this plugin on or select Builderlab. When you turn this plugin off, Buzz
selects the first other provider that is set up, such as TypeSafe with a saved
key.
