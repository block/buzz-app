# Channels

Where your conversations happen in Buzz: channels, direct messages, and threads, all in **Messages**.

## Getting started

1. Open **Messages**.
2. Choose **Create channel** in the sidebar, or start from a **Template**.
3. Type # in a message to link to another channel.
4. Choose **Channel actions**, then **View canvas** to open the channel's shared Markdown beside the conversation. Edit it and choose **Save Canvas**, or open **History** to inspect and restore earlier versions. In archived channels, Canvas and History remain available to members as read-only views.
