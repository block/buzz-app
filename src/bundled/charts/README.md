# Charts

Draws `buzz-chart` code blocks in messages as bar, line, scatter, pie and other charts.

## Getting started

1. When an agent or teammate posts a code block marked `buzz-chart`, it appears as a chart.
2. Choose **View data rows** under a chart to read its values as a table, or **Expand chart** to see it larger.
3. Choose **Copy code block** to copy the chart's JSON.
