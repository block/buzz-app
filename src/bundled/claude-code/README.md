# Claude

Create agents that run Claude on your computer and answer you in Buzz. Each agent works in its own **Workspace** folder and can run commands and edit files on its own.

## Getting started

1. Go to **Settings** → **Agent setup** → **Harness defaults** → **Claude** to install Claude and sign in.
2. Choose **New agent** → **Create a new agent**, and pick **Claude** as the **Harness**.
3. Mention your agent in a conversation to give it work.
4. If Claude reviews protected agents' actions, run `claude setup-token` in Terminal and paste its token under **Sign in for reviews** in Claude's **Edit configuration**. Reviews need a Claude subscription; the token lasts a year.
