# Community appearance

Set the picture everyone sees for your community in the community list.

The plugin is on by default; **Settings → Plugins → Manage plugins** can turn it
off. It appears under **Community admin** in Settings when you select a
community where you are an owner or admin.

## Getting started

1. Go to **Settings → Community admin → Community icon**.
2. Click **Choose image…** to upload a picture, or **Remove icon** to clear it.
