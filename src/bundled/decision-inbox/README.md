# Decision Inbox

Keep Buzz messages that need Laura's decision and a handoff in one place. Each item stays linked to its source message and is saved on this device for the current account and community.

## Getting started

1. Open a message's menu and choose **Save to Decision Inbox**. Enter the question and next actor.
2. Open **Decision Inbox** to see what needs a decision or handoff.
3. Use **Update** to record the decision and mark the handoff done. **Open source** returns to the message.
