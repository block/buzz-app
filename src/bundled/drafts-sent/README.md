# Drafts & sent

Brings the messages you started but did not send, and the ones you did, together in one place. Each sent message shows who replied after you, so you can see which conversations are waiting on you.

## Getting started

1. Open **Drafts & sent** in the sidebar. The count beside it is how many drafts you can still send; a draft in an archived conversation stays listed, marked Archived, but isn't counted.
2. Select a draft to pick it up where you left off, or a sent message to jump to it. Use a draft's trash button to clear it.
3. Search by conversation or by what you wrote.
