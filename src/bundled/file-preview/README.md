# File Preview

Read Markdown and plain text files beside a conversation.

## Getting started

1. Select a sent Markdown or plain text attachment to open its preview.
2. Use the separate **Download** control to save the file.
3. Close the **File preview** tab to return to the conversation.

Previews support UTF-8 files up to 100 KB. Raw HTML and remote images are omitted.
If a preview cannot load, choose **Retry** or download the file.

To turn previews off, disable **File Preview** in **Settings → Plugins → Manage plugins**.
