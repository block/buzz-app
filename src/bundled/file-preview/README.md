# File Preview

Read Markdown, source code, and common text files beside a conversation.

## Getting started

1. Select a supported sent attachment to open its preview.
2. Use the separate **Download** control to save the file.
3. Close the **File preview** tab to return to the conversation.

Supported text formats include JSON/JSONL, CSV/TSV, logs, YAML/TOML and configuration
files, XML/HTML/CSS, common source code, and diff/patch files. These display as literal
text. Markdown uses formatted text, omitting raw HTML and remote images.

Previews support UTF-8 files up to 100 KB. PDFs, Office documents, archives, and
other binary files remain downloads. If a preview cannot load, choose **Retry**
or download the file.

To turn previews off, disable **File Preview** in **Settings → Plugins → Manage plugins**.
