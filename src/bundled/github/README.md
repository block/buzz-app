# GitHub

Preview GitHub repositories, pull requests, issues, and commits without leaving Buzz.

## Getting started

1. Pull request links in messages show the pull request's state as their
   icon, kept current while shown. Click any github.com link to open it in a
   side panel, or turn on **Open GitHub links in browser** in Settings to open
   them in your browser instead (the panel then can't open from the sidebar
   either).
2. On a pull request, switch between **Discussion** and **Checks**.
3. Choose **Open on GitHub** to see the full page.
