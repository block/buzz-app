# Math equations

Shows LaTeX math in messages as typeset equations, so agents and teammates can write formulas the way they already do.

## Getting started

1. Write math in a message: `$e^{i\pi}+1=0$` or `\(a^2+b^2\)` inline, and `$$…$$` or `\[…\]` for a display equation. A code block marked `math` also works. Prices such as "$5 and $10" stay as text.
2. Choose **Σ** in the composer to write an equation with a live preview. Start from a template (fraction, root, sum, integral, matrix, cases, chemistry and more) if you don't know the LaTeX. Inside math, type `\` and a few letters to get command suggestions.
3. Choose **Expand equation** on a display equation or math block to see it large, then **Copy LaTeX**, or **Copy MathML** to paste it into Word or Pages as an equation.
4. Agents get a `math_check` tool that checks the math in a draft before they send it.
