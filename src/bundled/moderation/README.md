# Membership

For owners and admins of the selected community. Your role determines which
invitations, role changes and removals are available. Changes apply to that
community.

Moderation is a separate plugin for authorized relay staff working across
communities. Being a community owner or admin does not grant relay staff access.

## Getting started

1. Go to **Settings → Administration → Membership**.
2. Choose **Invite members** to add someone or copy an invite link.
3. Use a member's menu to manage their role or remove access, according to your permissions.
