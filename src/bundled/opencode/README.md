# OpenCode

Create agents that run OpenCode and answer you in Buzz. Each conversation continues its own agent session.

## Getting started

1. Install [OpenCode](https://opencode.ai) so `opencode` is on your PATH. Buzz does not include it.
2. Sign in to your provider with `opencode auth login`.
3. Go to **Agents**, create an agent with **OpenCode** as its **Harness**, and mention it in a conversation to give it work.
