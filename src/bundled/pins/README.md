# Pins

Keeps important messages one click away for everyone in a channel.

## Getting started

1. Open a message's menu and choose **Pin to channel**. A pin icon appears beside its time.
2. Choose the pin button in the channel header to see the channel's pinned messages, newest first, and select one to jump to it.
3. Choose **Unpin** on a pin you made. Channel owners and admins can unpin anyone's pin, which the channel shows as a removed message.
