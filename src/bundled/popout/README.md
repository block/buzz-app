# Pop-out windows

Keep a thread in view, and answer it, while the main Buzz window moves on.

## Getting started

1. Open a message's actions menu (the `⋯` on a message that has a thread) and choose **Open thread in new window**.
2. Read and reply in the new window. Your draft is the same one the thread shows in the main window.
3. Choose **Open in main window** to bring the thread back into the main window; the pop-out stays open until you close it.
