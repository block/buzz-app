# World land shapes

world-land.json contains SVG paths from Natural Earth 1:110m land polygons, rounded to two decimal places. Coordinates are longitude and negated latitude.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
Used by the profile daylight map.
