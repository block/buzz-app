# Reminders

Saves messages for later, with an optional due time.

## Getting started

1. Open a message's menu and choose **Remind me**.
2. Keep **No due time** (the default), or pick a time like **In 1 hour** or **Tomorrow at 9am**, and add a note if you like.
3. Open **Reminders** in the sidebar to see what's coming up, and **Snooze** or **Mark done** when you're ready.
4. Expand **Completed** to find finished reminders and open their original messages. This section is collapsed by default.
