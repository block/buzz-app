# Reminders

Brings a message back to your attention at a time you choose.

## Getting started

1. Open a message's menu and choose **Remind me**.
2. Pick a time, like **In 1 hour** or **Tomorrow at 9am**, and add a note if you like.
3. Open **Reminders** in the sidebar to see what's coming up, and **Snooze** or **Mark done** when you're ready.
