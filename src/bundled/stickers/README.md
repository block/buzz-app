# Stickers

Turns an image in a message into your own custom emoji for messages and reactions.

## Getting started

1. On a message with an image, open **More** and choose **Make sticker**.
2. In the Mac app on macOS 14 or later, the subject is lifted off the background. Turn off **Remove background** to keep the whole image.
3. Give it a name and choose **Save sticker**. Type the name between colons, like :my-sticker:, to use it.
