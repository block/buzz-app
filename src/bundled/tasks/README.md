# Tasks

A task holds the context for a piece of work, so anyone can pick it up later.

## Getting started

1. Open **Tasks** and choose **New task**. Give it a title, choose where it lives, and add a description and images if they help.
2. In a chat or channel, choose **Tasks** in its header to see the tasks that live there or are linked there, make one, or link an existing one.

You can also ask your agent to make a task from a conversation, or to find what you should work on.

- Every task lives in one place: a project, a channel or a chat. Whoever can open that place can see the task, and whoever can post there can edit it. Guests can only view.
- The Tasks page groups tasks by project. A task in a channel or chat filed in a project shows under that project.
- A task has a status (To do, In progress, Done or Cancelled) and up to four people assigned. Starting a task assigns you.
- Moving a task changes who can see it. Before it moves, you see which places' people gain or lose access.
- Linking a task to a conversation never changes who can see either one. Only people who can read the conversation see the link.
- A task link in a message shows the task's title and status, and opens it. Creating a task posts nothing.
- If someone else saves a task while you're editing it, your text is kept and you choose what to save.
