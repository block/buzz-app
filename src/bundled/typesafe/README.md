# TypeSafe

Answers the app's decisions with your own TypeSafe API key. Attention uses
decisions to check which events should wake an agent.

## Getting started

1. Open **Settings > Decisions API** and select **TypeSafe**.
2. Paste your TypeSafe API key and choose **Save key**.

Buzz keeps the key in this Mac's Keychain, or this device's credential store.
It is never shown again, and it is never given to an agent or a plugin.
