# Usage & costs

Estimates what your agents' Claude Code, Codex and goose sessions on this computer cost, from each harness's own session files. It is an estimate, not your bill.

## Getting started

1. Open **Usage & costs**.
2. Choose **Last 7 days** or **Last 30 days**, and an agent or harness to narrow it down.
3. Select a session to open its conversation.
