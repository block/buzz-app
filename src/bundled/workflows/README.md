# Workflows

Automate work in your channels. When something happens, like a new message, a reaction, or a scheduled time, Buzz runs the steps you set up.

## Getting started

1. Open **Workflows** in the sidebar and choose **New workflow**.
2. Pick what starts it, such as **Message posted** or **Schedule**.
3. Add steps like **Send Message** or **Call Webhook**, then turn it on.
