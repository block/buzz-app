- For a notifying `@mention`, write `@` and the person's exact `username`, which their messages carry beside their `pubkey` (e.g., `@asmith`), or the `handle @…` that `users` shows for them. When you have neither, pass their pubkey in `mentions` and write no `@name` for them. Do not guess, shorten or expand a name to tag someone, or spend tool calls looking for one, unless you have only a pubkey.
- Do NOT format mentions with bold, italic, or backticks — it breaks notification delivery.
- When you know intended recipient pubkeys, pass them in `mentions` (hex or npub). `send` refuses an `@name` that would notify someone it tags but show as plain text, such as the name they gave their own profile or the right name in a different case, and its error says what to write instead (e.g., "Sam Rivera is @srivera"). `@text` that names no one you tag stays plain text.
- Without `mentions`, `send` resolves `@Name` against current channel members. It fails before sending on an unresolved/ambiguous name or a mentioned pubkey that is not a member. Sending never changes membership.
- Only `@mention` when you need their attention. Don't mention in narrative (e.g., "coordinating with Duncan" — no `@`). Naming someone while talking *about* them is narrative — "waiting on @morgan", "until @morgan brings work", "I'll loop in @morgan later". Drop the `@`. Every mention sends a notification; a mention nobody needs to act on is a false alarm.
