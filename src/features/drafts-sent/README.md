# Drafts & sent

Built into Messages, with the conversation sidebar retained while you browse. Brings the messages you started but did not send, and the ones you did, together in one place. Each sent message shows who replied after you, so you can see which conversations are waiting on you.

## Getting started

1. Open **Drafts & sent** in the sidebar. The pencil count beside it is how many drafts you have.
2. Select a draft to pick it up where you left off, or a sent message to jump to it. Use a draft’s trash button to clear it.
3. Search by conversation or by what you wrote.
